# 🌧️ Rainfall Prediction Classifier

A Machine Learning project that predicts whether rainfall will occur based on weather conditions using classification algorithms.

---

## 📌 Features

- Data preprocessing and cleaning
- Feature scaling and encoding
- Rainfall prediction using ML models
- Model evaluation with accuracy score and confusion matrix

---

## 🧠 Algorithms Used

- Logistic Regression
- Random Forest Classifier
- K-Nearest Neighbors (KNN)

---

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
